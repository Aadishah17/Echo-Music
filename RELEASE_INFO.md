# Echo Music v5.1.9

- Redesigned the Account and Settings overflow menu to a modern Material 3 bottom sheet for a more expressive look.
- Integrated the AI Hub directly into the bottom navigation bar for quicker access.
- Added descriptive text to all top-level settings to clarify their purpose.
- Changed the default network IP version to Automatic for better compatibility.
- Added a back button overlay to the Ambient Mode screen for easier navigation.
- Fixed a bug where Apple Music V2 (Letter by Letter) lyrics animation would break apart combining characters in non-English languages (like Hindi/Punjabi) into dotted circles.
- Improved the settings search to properly index and search by category descriptions.
- Removed lossless music streaming, downloads, and tracking features entirely.
